# SVV Lab Task: Static Verification of C++ Code

Static code review of `game.cpp` (a small text-based monster battle game).
No code was run: all defects were found by reading the code.

## Files
- `game.cpp`: the code under review
- `1_Review_Checklist.md` / `.docx`: review checklist (8 categories)
- `2_Code_Review_Report.md` / `.docx`: detailed defect report

## Result
- Total defects: 22 (High: 12, Medium: 7, Low: 3)
- All 8 checklist categories contain at least one issue.
